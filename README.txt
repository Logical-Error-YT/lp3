DAA + ML Practical Codes (Python)

Folder DAA: five short .py programs for questions 1-5.
Folder ML: four Jupyter notebooks for questions 7-10.

Datasets:
- ML/uber.csv for Uber fare prediction (columns described in notebook)
- ML/spam.csv for spam detection (common SMS spam dataset columns accepted)
- ML/diabetes.csv for KNN (target usually named Outcome)

Install common packages:
pip install pandas numpy matplotlib scikit-learn jupyter nbformat

Run DAA files with: python filename.py
Open notebooks with Jupyter Notebook or Google Colab. Upload the required CSV dataset(s) to the same folder/runtime before running.
Note: N-Queens program fixes the first queen at (row 0, column 0), as requested; some N values have no solution with that fixed position.
